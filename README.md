Entry for the [make.fun bounty "The Robot Vacuum's Best Excuse"](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) — write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. A judge playing a tired homeowner picks the funnier line in pairs.

## The entry

`main.ts` (Node, no external dependencies) writes one deterministic line to `/output/entry.txt`:

> My cliff sensor mistook the rug fringe for a staircase, so I filed that corner under ‘certain death’ and went back to my dock.

The vacuum speaks for itself: its cliff sensor, its map, its dock — one clean turn at the end.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
